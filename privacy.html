Privacy policy

This policy covers this website and the Last Night Dossier Publisher, the tool the channel uses to upload its own videos to YouTube.

This website

This site is a set of static pages hosted on GitHub Pages. It sets no cookies, runs no analytics and has no forms. GitHub, as the host, may keep standard server logs such as IP addresses; see the GitHub Privacy Statement.

Last Night Dossier Publisher

The Publisher is used only by Last Night Dossier to manage its own YouTube channel. It is not offered to the public, and no one else signs in to it.

  • What it accesses. With the channel owner's consent, it uses the YouTube Data API to upload the channel's own videos and set their titles, descriptions, captions, thumbnails, playlists and publishing schedule.
  • What it stores. An OAuth refresh token for the channel, kept as an encrypted secret in the channel's private GitHub repository, plus the IDs and links of the videos it uploads. It does not read, collect or store data about viewers or other YouTube users.
  • Sharing. Nothing is sold or shared with third parties. Data goes only to Google, to perform the uploads.
  • Retention and revoking access. The token is kept while the Publisher is in use and deleted when it is retired. Access can be revoked at any time from Google Account permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The Publisher uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
